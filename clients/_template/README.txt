Template for a new client. Do not edit by hand to add a client: run
  node scripts/new-client.mjs <id> "Business Name" --coach "Full Name"
then edit clients/<id>/client.json and replace clients/<id>/logo.svg.
Optional: put icon-192.png, icon-512.png, icon-apple.png, coach-icon-192.png, coach-icon-512.png and
coach-icon-apple.png in clients/<id>/icons/ to use your own app icons instead of generated ones.
